# Análise de Dados de Vendas

## 📌 Objetivo
Analisar dados de vendas para identificar padrões de faturamento,
produtos mais vendidos e comportamento ao longo do tempo.

## ❓ Perguntas de Negócio
- Quais produtos geram mais faturamento?
- Como o faturamento varia ao longo do tempo?
- Existe diferença de vendas por dia da semana?
- Qual é o ticket médio?

## 🛠️ Ferramentas
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
